# Privacy Policy — Dramon Analytics

Last updated: October 19, 2026

Dramon Analytics is a private, single-user tool operated by the owner of the YouTube channel "Dramón IA" (contact: ericmun0206@gmail.com).

Data accessed: with the channel owner's consent, the tool reads that channel's own YouTube data and YouTube Analytics reports (for example views, watch time, audience retention, traffic sources and public comments) through the official YouTube Data API and YouTube Analytics API, using read-only scopes.

Use: the data is used only by the channel owner to evaluate and improve the channel's videos.

Sharing: the data is not sold, shared or transferred to any third party, and is not used for advertising.

Storage: access tokens and reports are stored only on the owner's own computer. The owner can delete them at any time and can revoke access at https://myaccount.google.com/permissions

Google API Services: use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used in accordance with the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).
