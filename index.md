# Dramón IA — Dramon Analytics

Dramon Analytics is a private tool used only by the owner of the YouTube channel "Dramón IA" to read that channel's own YouTube Analytics data (views, watch time, audience retention) in order to improve future episodes.

It requests read-only access (youtube.readonly, yt-analytics.readonly) and is not offered to other users.
